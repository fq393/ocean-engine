# 中文 HUD 与船舵方向修正设计

## 目标

将左上角驾驶 HUD 改为中文，并让驾驶视角中的 `A`/`D` 与用户直觉一致：
`A` 左转，`D` 右转。修复应保持现有海洋、天气、碰撞、尾流和物理接口不变。

## 现状与根因

- `src/main.ts` 当前写入英文标题、操作提示和初始天气文案。
- `OceanDemo` 每帧更新动态天气文案，目前只区分英文的晴天和暴风雨状态。
- `BoatController.intentFromKeys` 当前返回 `KeyD = +1`、`KeyA = -1`。
- 现有船体 yaw 坐标约定使上述舵值在追逐视角中呈现为反向，因此问题位于输入层语义映射，不应修改船体动力学或模型坐标。

## 设计

### HUD 文案

HUD 使用固定中文结构，保留后端能力状态但改为中文表达：

- 眉题：`实时海洋与天气模拟`
- 标题：`热带航道`
- 能力状态：`WebGPU 可用 · 当前使用 WebGL2 渲染`，或 `当前使用 WebGL2 渲染`
- 分隔标题：`操作说明`
- 操作行：`W 前进 · S 后退`
- 操作行：`A 左转 · D 右转`
- 操作行：`T 切换晴天 / 暴风雨`

动态天气状态使用中文：

- 晴天：`当前天气：晴朗`
- 暴风雨：`暴风雨 {stormPercent}% · 降雨 {rainPercent}%`

WebGL2 不可用时显示中文错误提示，避免用户看到英文故障信息。

### 输入修正

只调整 `BoatController.intentFromKeys` 的舵值映射：

- `KeyA` 返回正舵值，表示左转。
- `KeyD` 返回负舵值，表示右转。
- W/S 油门、同时按下相反按键归零、按键边界和清理逻辑保持不变。

不修改 `BoatDynamics` 的 rudder 物理公式，避免影响测试钩子、碰撞、尾流和后续 AI 控制器。

## 测试策略

1. 单元测试：更新 `BoatController` 映射断言，明确 A/D 的符号；继续覆盖 W/S 互斥和边界行为。
2. 浏览器测试：验证 HUD 包含中文标题和操作说明；分别按 A、D，断言船体 yaw 变化方向符合左/右转语义。
3. 视觉回归：中文 HUD 会改变四张现有视觉基线，需要重新生成并人工检查；海面、雨幕、闪电、尾流画面本身不做无关改动。
4. 完整验证：运行 `npm test`、`npm run build` 和 `npm run test:e2e`。

## 非目标

- 不加入语言切换菜单。
- 不修改天气逻辑、海浪参数、镜头距离或 3D 模型。
- 不把当前 WebGL2 渲染器改造成 WebGPU 渲染器。
